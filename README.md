# 🦇 Wing Run — Official Website

The official landing page for **Wing Run**, a pixel-art Android arcade game. The website introduces the game, explains how to play, highlights its features, and provides a direct download link for the Android APK.

## 🌐 Live Website

**[Play / Download Wing Run](https://wingrun.vercel.app/)**

## 📲 Download the Android App

Download the latest APK directly from this repository:

**[⬇️ Download Wing Run for Android](https://github.com/JosueEtta/wingrun/raw/refs/heads/main/app/wing-run.apk)**

APK file: `app/wing-run.apk`

After downloading, open the APK on your Android device. If prompted, allow installation from that source in your Android settings, then complete the installation.

> Wing Run is currently available for Android.

## 💻 Game Source Code

The website and the Flutter game source code are maintained in separate repositories.

- **Website repository:** [JosueEtta/wingrun](https://github.com/JosueEtta/wingrun)
- **Flutter game source code:** [JosueEtta/wing-run](https://github.com/JosueEtta/wing-run)

To clone the game source code:

```bash
git clone https://github.com/JosueEtta/wing-run.git
cd wing-run
```

See the game repository's README for setup instructions and details about the Flutter project.

## ✨ Website Features

- Responsive landing page for desktop and mobile.
- Game introduction and gameplay instructions.
- Feature highlights and game artwork.
- Direct Android APK download buttons.
- Scroll animations using AOS.
- Tailwind CSS styling.

You can also use the VS Code Live Server extension for local development.
